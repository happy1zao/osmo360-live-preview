# samples/ —— 证据与语料（占位目录）

本目录**不随仓库提供任何样本文件**。历史上这里存放过真机抓包（`.pcap`）、
解码码流（`.h264` / `.h265`）、解码帧（`.png`）、原始缓冲（`.raw` / `.gray`）
等大体积产物，单份可达数十 MB，按仓库约定一律不入库（见根目录 `.gitignore`）。

## 本地使用时的预期布局

自己抓包 / 解码后，可按主题在此目录下新建子目录存放，例如：

```
samples/
├─ rec/            # 录制产物与逐帧截图（本地生成，不入库）
├─ *_tail.bin      # 抓包字节样本
└─ README.md       # 本说明
```

## 文档里引用过的样本名

历史文档中出现过 `live20.h264`、`mimo.pcap`、`mimo_cold_handshake.pcap`、
`g74_f317.png`、`rec/c69.LRF` 等文件名，它们是**当时真机采集的私有样本**，
不在仓库内；复现实验时请先用对应工具在自己的设备上采集，再把路径传给脚本。
